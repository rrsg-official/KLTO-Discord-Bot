## About

**KALI LINUX TERMINAL OPERATOR** is a custom-developed Discord bot designed to provide interactive commands, specialized features, server utilities and entertainment.

The project combines multiple systems into one Discord bot, with a focus on functionality, customization and continuous development.

## Features

- **Custom Commands** — A collection of custom commands and interactive systems.
- **PhenixGPT** — An artificial intelligence-inspired question and answer feature.
- **Escape Room Event** — A multi-room interactive Discord event with puzzles, roles, buttons and progression.
- **Server Utilities** — Debugging and information commands.
- **Updates System** — Version announcements and development information.
- **Message Detection** — Additional message-based functionality.

## Commands

| Command | Description |
|---|---|
| `/help` | Displays bot help information. |
| `/debug` | Displays debugging and status information. |
| `/use` | Accesses the custom command system. |
| `/phenixgpt` | Opens the PhenixGPT question system. |
| `/updates` | Displays the latest bot updates. |
| `/playerfinishkahoot` | Provides the Kahoot-related functionality. |

Some features are restricted to designated Discord servers.
